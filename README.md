# 🎀 网易云音乐歌单整理工具

[![license](https://img.shields.io/badge/license-AGPL--3.0-orange)](LICENSE)
[![Tampermonkey](https://img.shields.io/badge/脚本管理器-Tampermonkey-ff69b4)](https://www.tampermonkey.net/)

一个网易云音乐歌单自动整理油猴脚本。

## 🌸 功能特性

- 🎯 自动识别歌单里的**专辑歌曲**和**单曲**
- 🗂️ 专辑歌曲会按**专辑**分组
- 📅 专辑组之间按**专辑发行时间从新到旧**排列
- 🔀 同一张专辑里的歌曲，按**原专辑曲目序号倒序**排列（如果歌单里只收了专辑的一部分，就只排这些）
- 🎤 单曲按**歌手**分组
- 🔤 歌手组之间按**歌手首字母 A-Z** 排列（中文按拼音，英文按字母）
- ➕ 如果某位歌手既有单曲又有专辑，ta 的单曲组会**整体插到这位歌手最新专辑的上方**
- 💾 整理完成后会**修改歌单顺序**

## 📦 安装方法

### 第一步：安装脚本管理器

你需要安装以下任意一个用户脚本管理器：

- [Tampermonkey](https://www.tampermonkey.net/)（最常用）
- [Violentmonkey](https://violentmonkey.github.io/)

安装完成后，浏览器右上角会出现脚本管理器图标。

### 第二步：安装本脚本

有两种方式，任选其一：

#### 方式一：直接点击安装（推荐）

点击下面的按钮，脚本管理器会弹出安装页面：

   [![安装脚本](https://img.shields.io/badge/安装脚本-点击安装-ff69b4)](https://raw.githubusercontent.com/lag1c/netease-music-playlist-organizer/main/script.user.js)

#### 方式二：手动复制安装

1. 打开脚本文件 `script.user.js`
2. 复制全部代码
3. 点击脚本管理器图标 → “新建脚本”
4. 粘贴代码并保存

## 🧁 使用说明

1. 打开网易云音乐**网页版**（ https://music.163.com/ ）
2. 进入你想整理的歌单
3. 页面右下角会出现一个粉粉的 **“✨ 整理一下”** 按钮
4. 点击按钮，确认后按钮会变成进度提示
5. 整理成功后页面会自动刷新，顺序就变整齐啦

不需要你手动拖拽歌曲，不用新建歌单。

## 💭 一点小碎碎念

这个脚本的诞生，纯粹是因为我的歌单洁癖。  
我按专辑听歌，喜欢列表必须是一张专辑一张专辑排好。

手动拖歌实在忍不了，就写了这个脚本。  
如果你有类似的症状，希望这个脚本能救你一命。

## ❓ 常见问题 / 注意事项

- 只支持网易云音乐**网页版**，客户端（桌面端、手机 App）不适用。
- 需要登录网易云账号。
- 只能整理自己创建或有权限修改的歌单，别人的歌单如果没有编辑权限，脚本会失败。
- 歌单很大时可能需要等一会儿。
